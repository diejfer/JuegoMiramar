# Juegos Miramar

Repositorio de juegos simples desarrollados en HTML, CSS y JavaScript con ayuda de un agente de IA.
Todos los juegos están pensados para ejecutarse 100% en el navegador y ser usados desde celulares.

## URL del sitio
https://diejfer.github.io/JuegoMiramar/

## Índice de juegos
Cada juego vive en su propia carpeta y se accede con:

https://diejfer.github.io/JuegoMiramat/<game-slug>/

## Estructura del repositorio
- `index.html` → Home del sitio
- `README.md` → Este archivo
- `development_guidelines.md` → Reglas de desarrollo
- `shared/` → Código compartido (debug, helpers)
- `/<game-slug>/` → Carpeta de cada juego

## Home del sitio
La home incluye:
- Lista de juegos
- Botón para limpiar el LocalStorage de cada juego (por namespace)
